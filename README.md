# El reloj de las 24 ventanas · Adviento PCE

Calendario navideño cooperativo para las diez clases PCE de Y12/Y13.

## Subir a GitHub Pages

1. Descomprime el ZIP en tu ordenador.
2. Sube el contenido a tu repositorio. `index.html` debe quedar en la raíz, junto con `app.js`, `tasks.js`, `christmas.css` y la carpeta `assets`. Sube los archivos descomprimidos, no el ZIP.
3. En Settings → Pages selecciona Deploy from a branch, rama genially y carpeta / (root). Guarda y espera a que GitHub muestre el enlace publicado.

El archivo `.nojekyll` es opcional para este juego; inclúyelo si aparece al seleccionar los archivos. No se requiere instalar dependencias ni ejecutar una compilación.

## Jugar

Abre el enlace publicado y dirige el juego desde el ordenador docente. Las 24 ventanas incluyen pistas, comprobación de códigos y diario de hallazgos. Entrega los sobres físicos siguiendo la guía docente entregada por separado.

La partida se guarda en cada navegador. No se sincroniza automáticamente entre alumnos u ordenadores. En «Mi partida» puedes exportar, importar o reiniciar. Una nueva dirección de GitHub Pages comienza con su propio progreso; para trasladar la partida anterior, expórtala desde el sitio anterior e impórtala en el nuevo.

## Material docente

Este paquete contiene solo el juego. Los imprimibles y el solucionario se conservan aparte; no es necesario subirlos al repositorio.
